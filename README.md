
# 🎓 CareerBridgeAI – Student Career Portal

## 📌 About the Project

CareerBridgeAI is a database-driven university career portal designed to connect students with recruiters. It provides a platform where students can explore job opportunities, apply for positions, and manage their career activities, while recruiters can post jobs and manage applications.

The project was developed as part of the Database System & Applications course at NUIST.

## 🚀 Key Features

- Student registration and login
- Recruiter registration and login
- Student dashboard
- Recruiter dashboard
- Job posting and management
- Job searching and browsing
- Online job applications
- Database-driven user and job management
- Prevention of duplicate job applications

## 🗄️ Database

The application uses MySQL to manage student accounts, recruiter accounts, job listings, and job applications.

The database supports relational data management and maintains relationships between different system entities.

## ⚙️ Installation and Setup

1. Clone this repository:

   `git clone https://github.com/NaidKhan/careerbridge-ai-student-career-portal.git`

2. Navigate to the project directory.

3. Create a Python virtual environment:

   `python -m venv .venv`

4. Activate the environment:

   Windows:
   `.venv\Scripts\activate`

5. Install the required packages:

   `pip install flask pymysql python-dotenv`

6. Configure your MySQL database and create the required database.

7. Create a `.env` file containing your local database credentials.

8. Run the application:

   `python app.py`

9. Open the local application URL displayed in your terminal.
